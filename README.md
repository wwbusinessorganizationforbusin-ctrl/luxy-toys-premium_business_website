# Little Luxe Toys — Premium Toy Boutique Website

A responsive product catalogue for Little Luxe Toys, styled with a fresh playful-premium look: deep teal, warm coral, sunny butter yellow, soft sage and cream. Customers can browse and search the catalogue, add products to an order list, and prepare an order through WhatsApp.

## Run locally
1. Extract the ZIP file.
2. Open `premium_business_website/index.html` in a modern browser. For best results, serve the folder with a simple local web server.
3. Product catalogue data is in `products.json`; product images are in `assets/products/`.

## Update products
Edit `products.json` to update product names, descriptions, categories and prices. Current display names are non-numbered placeholders; replace them with the correct names for each toy before publishing. Keep image paths matched to the correct products. Prices and availability should be confirmed by the business where not supplied.

This is a WhatsApp-ordering catalogue, not an online payment system. Confirm prices, stock, delivery, returns, privacy wording and business hours before launch. Test the website on mobile and desktop browsers before sharing it with customers.
